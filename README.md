In this repository, I implement simplified versions of various scripts and notebooks related to modeling and simulation of molecular systems. This repository is intended to serve as a cheet sheet for anyone who wants to quickly learn how to conduct certain experiments or algorithms in the field of molecular modeling and simulation and how machine learning techniques can be applied to this field.

The repository is organized into a number of tutorials, each of which focuses on a specific topic or technique. Each tutorial contains a set of scripts and notebooks that demonstrate how to implement the relevant algorithms and techniques in practice.

This is a work in progress repository and I will continue to add more content as I encounter and develop it.

## Installation
To install the required dependencies, make sure `uv` is installed and run the following command:

```bash
uv sync
```
